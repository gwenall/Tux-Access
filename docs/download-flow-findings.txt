in the existing string inventory; their presence is not attribution to this
particular endpoint. Unauthorized Metalink errors indicate an authentication
failure case is represented, but not which credentials or header format it uses.

redirects or requesting CDN payload URLs. The independent downloader should
keep account Authorization tied to the verified NI API origin and should not
forward it to a different origin based only on an HTTP redirect or Metalink URL.
That is an independent implementation policy, not observed proprietary behavior.
